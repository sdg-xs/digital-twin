# Hemy360 · SOL10 digital twin concept

React application with actual SOL10 IFC geometry displayed through That Open Fragments and Three.js. The interface follows the final corrected tokens and patterns in `docs/Hemy-Solutions-Design-System-Corrected.html`: Poppins, navy #002340, blue #1769E0, background #F7FAFF, neutral surfaces, source-aware context panels and compact tables.

## Start development

Node.js 22.12+ or 24 and npm are required.

```powershell
npm install
npm run dev
```

Open http://127.0.0.1:4174. To build: `npm run build`. To inspect the production build without installing packages: `node scripts/serve-preview.mjs`, then open http://127.0.0.1:4174. The packaged `dist` is ready to serve.

## What is implemented

- Actual SOL10 geometry and source material colors, not a schematic or generated building.
- Orbit, pan, zoom, top view, reset, model selection and selection from the explorer.
- Original IFC names, classes, Express IDs, GlobalIds, storey relationships and property sets.
- Storey and IFC-category visibility filters; text search filters the element list.
- Locate and isolate selected elements through That Open model APIs.
- Adjustable horizontal section plane and model opacity slider.
- Element register, integration status and browser-local sample work orders linked to real IFC identities.
- Hemy styling with locally embedded Poppins font data from the supplied design system.

## Data and provenance

Original input: `C:\Users\StevenGomba\OneDrive - HEMY AS\Desktop\Omniverse Working Files\PROPERTIES\SOL10\IFC\SOL10.ifc` (350,805,557 bytes, IFC4X3_ADD2, Revit 2027 export dated 19 October 2026).

`public/models/SOL10.frag` is generated by `@thatopen/fragments` 3.6.0 `IfcImporter`, using web-ifc 0.0.77. This official derivative is approximately 50 MB and includes the model's own property relationships. No custom mesh decimation is used in the delivered viewer. The original IFC is never modified.

`public/models/SOL10-metadata.json` is an extracted index of 13,600 geometric elements, 21 storey entities and 33 IFC categories for the React explorer. Storey names may repeat because the IFC contains separate spatial branches; IDs distinguish them. This is a geometric element index, not a verified CMMS asset register. IFC spaces/opening voids are excluded from the explorer index. Native Fragments picking can encounter an item outside that index; further expansion of the index is a future task.

The source IFC has been converted with `COORDINATE_TO_ORIGIN` and 12 circle segments. This is a visual derivative, not a surveying or fabrication tool. All operational integrations remain disconnected. Work orders are sample browser records, stored under `hemy-sol10-tickets` in localStorage; they are not written into the IFC or an external system.
